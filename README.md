# Приглашение на юбилей Марии

## Как открыть
Откройте папку в VS Code и запустите `index.html` через расширение **Live Server**
(правый клик по файлу → «Open with Live Server»). Можно и просто двойным кликом открыть в браузере.

## Структура
```
index.html          — вёрстка и все тексты
css/style.css       — стили (цвета и шрифты — в блоке :root в начале файла)
js/script.js        — таймер, музыка, заставка, календарь, анкета гостя
google-apps-script/ — код для приёма ответов в Google Таблицу
assets/images/      — фотографии
assets/audio/       — музыка
```

## Что положить в папки
| Файл | Где показывается |
|---|---|
| `assets/images/hero.jpg` | овал-«ноль» в цифре 50 на первом экране (лучше вертикальное фото) |
| `assets/images/photo-1.jpg` | первое фото рядом с текстом приглашения |
| `assets/images/photo-2.jpg` | второе фото рядом с текстом |
| `assets/images/contact.jpg` | круглое фото в блоке «Остались вопросы?» |
| `assets/audio/music.mp3` | фоновая музыка |

Пока файла нет, на его месте видна заглушка с подсказкой пути. Имена можно поменять — тогда поправьте их в `index.html`.

## Что где менять
- **Дата праздника**: в `index.html` атрибут `data-date` у блока `#timer` и текст дат; в `js/script.js` объект `EVENT` вверху.
- **Адрес**: в `index.html`, секция «Где и когда» (текст, ссылка на карту и `iframe`).
- **Телефон и WhatsApp**: в `index.html`, секция «Остались вопросы?».
- **Цвета**: переменные `--bg`, `--gold`, `--champagne` и др. в начале `css/style.css`.

## Ответы гостей на почту и в Google Таблицу
Пока это не настроено, анкета отправляет ответ гостя вам в WhatsApp готовым сообщением.
После настройки гость просто нажимает «Отправить ответ», а вам приходит письмо,
и ответ добавляется строкой в Google Таблицу со всеми гостями.

1. Войдите в свой аккаунт Google и создайте новую таблицу (sheets.new), назовите, например, «Гости юбилея».
2. В меню таблицы: **Расширения → Apps Script**.
3. Удалите всё в редакторе и вставьте код из файла `google-apps-script/Code.gs`. Нажмите «Сохранить».
   Письма придут на почту этого аккаунта Google. Чтобы получать их на другой адрес
   (или на несколько), впишите его в `NOTIFY_EMAIL` в начале кода.
4. Проверка: вверху редактора выберите функцию **testSend** и нажмите **Выполнить**.
   Google попросит разрешения: «Проверить разрешения» → выберите аккаунт →
   «Дополнительные настройки» → «Перейти на страницу…» → «Разрешить».
   В таблице появится тестовая строка и придёт письмо. Строку потом удалите.
5. Нажмите **Начать развёртывание → Новое развёртывание**, тип — **Веб-приложение**.
   - «Запуск от имени»: **Я**
   - «У кого есть доступ»: **Все**
6. Нажмите «Начать развёртывание» и скопируйте ссылку веб-приложения (заканчивается на `/exec`).
7. В `js/script.js` вставьте её в `RSVP.googleScriptUrl` вместо пустых кавычек.

Лист «Ответы» с колонками создастся сам при первом ответе.
Бесплатный аккаунт Google отправляет до 100 писем в день, для приглашения этого хватит с запасом.
Если потом поменяете код скрипта, сделайте новое развёртывание («Управление развёртываниями → Изменить → Новая версия»).

Ответ, который гость уже отправил, запоминается на его телефоне: при повторном открытии он увидит его и сможет изменить.
В таблице тогда появится новая строка, актуальной считайте последнюю от этого человека.

Срок ответа («до 1 ноября») меняется в `index.html`, в секции «Вы придёте?».

## Как отправить гостям
Сайт нужно выложить в интернет, например бесплатно на GitHub Pages, Netlify или Vercel
(достаточно загрузить всю папку). После этого у приглашения будет ссылка.
